算盘：先表示，再按口诀加减

本章从算盘开始，由浅入深。先学会把一个数拨在盘上，再计算 \(152+763\)：从个位向左，一档一档相加，记下进位。乘、除这一章还不引入。

一、本章要算什么

这一章要计算 \(152+763\)。使用的工具是算盘。中国长期用算盘做加减。这一章只讨论十进制的加和减。乘、除可以看成反复的加减，这一章还不引入。

二、先把 152 表示出来

计算以前，先要在算盘上把数拨出来。这叫做表示。要算 \(152+763\)，第一步是把 152 拨到盘上。

算盘分成一档一档，每一档对应一个数位。从右往左依次是：个、十、百、千。因此 152 表示成：百位 1，十位 5，个位 2；千位是 0，珠子全部离梁。

每一档怎样表示 0 到 9？梁上面有一颗上珠，当 5；梁下面有四颗下珠，每颗当 1。珠子拨向梁才计数，拨离梁就不计数。一档上的数是

\(5\times\)（靠梁的上珠颗数）\(+\)（靠梁的下珠颗数）

传统中国算盘是上二下五，一档可以大于 9，方便旧制斤两。十进制加减只需要 0 到 9。这一章用上一下四，每一档恰好表示十进制的一位。

把 152 拨到盘上：个位两颗下珠，十位一颗上珠（表示 5），百位一颗下珠。千位珠子全部离梁，表示 0。这时盘上读出的数是 152，加法还没有开始。

三、加法：一档一档，加上进位

152 拨好以后，再加 763。步骤和纸上的竖式相同。从个位开始，向左逐档计算。每一档要加上三个量：本档原来的数、加数这一位、从右边传来的进位（0 或 1）。

个位：\(2+3=5\)。5 用一颗上珠表示，下珠全部离梁。本档变成 5，不进位。

十位：\(5+6=11\)。一档只能留下 0 到 9，所以本档留下 1，向百位进 1。

百位：1 + 7，再加上进位 1，得 9。9 用一颗上珠加四颗下珠表示。千位仍是 0。

盘上读出 915，与竖式结果相同。每一步只处理当前这一档，以及进位 0 或 1。

可以换成别的两位数或三位数。这一章只用千、百、十、个四档，结果不超过 9999。

四、减法

减法从个位向左做。本档不够减时，向左边借 1，当作 10 再减。例如 \(915-763\)，逐步拨回去，得到 152。

乘、除这一章不讲。它们是把加减重复多次，口诀更长。

这一章后面一直要用的，是下面三条：

  1. 计算以前，先把数表示成盘上的珠子位置。
  2. 运算按确定的口诀进行，一次只改当前这一档。
  3. 档与档之间，只需要记住进位（或借位）是 0 还是 1。

口诀相同，任何人拨完都得到同一个结果。快慢不影响结果。

五、更早的工具：算筹

算盘之前，中国用算筹：小棍按个、十、百、千摆在桌上。正负可以用红筹、黑筹区分。算盘把珠子固定在档上，拨起来更快，也不容易碰乱。

两种工具都用十进制位值，都按口诀做加减。算术规则相同，改变的是记数的方式。

六、本章小结

在算盘上计算，先要把数表示成各档珠子的位置，再按口诀从个位向左加或减。进位（或借位）是档与档之间唯一要记下的中间结果。加减是这一章的基本运算。

方法。 ① 选定一个加法，例如 \(152+763\)。② 先把被加数拨到盘上。③ 从个位向左，每一档计算：本档原有的数 + 加数这一位 + 进位；留下 0 到 9，满十向左进 1。④ 用竖式核对结果。
